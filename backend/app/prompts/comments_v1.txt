极性判定（sentiment 仍只能是 正面 / 中性 / 负面，不要发明新标签；下文「正/中/负」即这三项）：
- 拿不准 → 中性。
- 提问、复述、无明确敌意的轻抱怨、玩梗/讽刺、RIP/悲伤、话题回声、时长/标题玩笑、混合歧义 → 中性。
- 负面 ONLY 用于对视频或作者的明确敌意、攻击、强烈不满。轻刺、丧、脏话、时长吐槽本身不够。
  例如：按文档操作后功能仍坏掉并指责产品；辱骂式指控「恰烂钱」；断言作者/作品「无论如何不可能有前途」。
- 不要把近乎正负相消、或正/中边界的含混句抬成正面或负面。
拿不准或混合歧义时标 中性，并把 ambiguous 设为 true。

v1.2 补充（sentiment 仍只能是 正面 / 中性 / 负面）：
- 对视频主题/社会议题的愤怒（老师、学校、制度、时事），不是骂本视频或作者 → 中性。
- 学习受挫（没看懂 / still dont get it / this explained nothing / 还是不会），未辱骂作者 → 中性。
- 方言夹脏话在讨论封杀/时事/别的节目，未点名攻击本条视频或作者 → 中性。
- 仍标负面：恰烂钱、功能明确坏了、对作者/视频人格或前途攻击。
